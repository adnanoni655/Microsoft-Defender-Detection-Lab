# Uploading this project to GitHub

1. Extract `Microsoft-Defender-Detection-Lab.zip` on your computer.
2. Go to https://github.com and sign in.
3. Click **New repository**.
4. Name it `Microsoft-Defender-Detection-Lab`.
5. Choose **Public** if you want recruiters to see it, then create the repository.
6. In the new empty repository, choose **Add file → Upload files**.
7. Open the extracted project folder and upload `README.md`, `INTERVIEW-NOTES.md`, and the `screenshots` folder contents. If the browser does not accept folders, create the `screenshots` folder in GitHub first, then upload its images.
8. Commit the files.
9. Open the repository page and check that the README images display correctly.

Do not upload the EICAR test file itself. The screenshots included here are the real screenshots provided during the lab; they have only been copied and renamed for organization.
